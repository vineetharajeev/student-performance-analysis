# Student Performance Analysis 📊

A simple Data Analytics project using Python, Pandas, and Matplotlib to analyze student performance.

## Features

* Stores student marks using a Pandas DataFrame
* Calculates individual average marks
* Calculates the class average
* Identifies the top-performing student
* Visualizes average marks using a bar chart

## Technologies Used

* Python
* Pandas
* Matplotlib

## How to Run

```bash
pip install pandas matplotlib
python student_analysis.py
```

## Analysis Performed

The project analyzes marks in:

* Mathematics
* Science
* English

It calculates the average performance of each student and identifies the student with the highest average.

## Visualization

A bar chart is generated to compare the average marks of all students.
